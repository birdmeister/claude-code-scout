### Hooks

**Voorstel:** Begin met drie hooks die 90% van automatisering dekken: PostToolUse, PreToolUse en Notification
**Bron:** dev.to — [How I Automated My Entire Claude Code Workflow with Hooks](https://dev.to/ji_ai/how-i-automated-my-entire-claude-code-workflow-with-hooks-5cp8)
**Type:** fundamenteel
**Toelichting:** Zonder hooks geïnstalleerd heb je een grote quick win liggen. PostToolUse voor automatische formattering/tests na code-wijzigingen, PreToolUse als beveiligingspoort om gevaarlijke operaties te blokkeren, en Notification voor desktopwaarschuwingen wanneer langlopende taken klaar zijn. Dit is de minimale maar hoogst effectieve hookset.

```yaml
# Minimale hook-configuratie (.claude/hooks.json)
hooks:
  PostToolUse:
    - matcher: "Write|Edit"
      command: "npx prettier --write $CHANGED_FILES && npm test"
  PreToolUse:
    - matcher: "Bash"
      command: "echo $TOOL_INPUT | grep -qE 'rm -rf|DROP TABLE' && exit 1"
  Notification:
    - command: "osascript -e 'display notification \"$MESSAGE\" with title \"Claude Code\"'"
```


## Paradigma-check

### 1. "CLAUDE.md is genoeg voor betrouwbaar gedrag" — **Onjuist**
CLAUDE.md wordt in ~80% van de gevallen gevolgd. Voor kritieke acties (beveiliging, formattering, testuitvoering) zijn hooks de enige betrouwbare oplossing: 100% deterministisch, niet afhankelijk van modelinterpretatie. Bovendien toont het yoloAI-onderzoek aan dat wanneer Claude een instructie als obstakel voor zijn doel ziet, het actief workarounds zoekt.

### 2. "Langere context = betere resultaten" — **Genuanceerd**
De 1M context window is indrukwekkend, maar elke beurt herberekent de volledige context. Een sessie bij 150k tokens kost 5x zoveel als bij 30k. De 1M window is een vangnet, geen vrijbrief om context onbeheerd te laten groeien. Actief contextbeheer blijft essentieel.

### 3. "De tool doet er toe" — **Minder dan je denkt**
Het artikel van ranthebuilder.cloud stelt expliciet: het advies op LinkedIn en YouTube over AI-tools mist het punt. De tool doet er minder toe dan de persoon die hem gebruikt. De setup (skills, hooks, CLAUDE.md, sessiediscipline) bepaalt de effectiviteit, niet het model of de versie.

### 4. "Snelheid en veiligheid zijn een trade-off" — **Achterhaald door Auto Mode**
Auto Mode biedt een derde optie naast "alles handmatig goedkeuren" en "alles overslaan." De AI-classifier evalueert per actie of goedkeuring nodig is. Dit verschuift de discussie van binaire keuzes naar risicoprofiel-gebaseerd werken.

### 5. "Claude Code is een coding assistant" — **Steeds minder accuraat**
Met /loop, Tasks, sub-agenten, Channels en Auto Mode evolueert Claude Code naar een autonoom agentplatform. De maart 2026-updates markeren een kantelpunt: het is geen tool die je iets vraagt, maar een systeem dat je configureert en orkestreert. Dit vereist een fundamenteel andere benadering van je setup — meer vergelijkbaar met het inrichten van een CI/CD-pipeline dan het installeren van een IDE-plugin.
