

# Claude Code Scout — weekrapport 3 april 2026

## Samenvatting

Deze week was uitzonderlijk rijk aan Claude Code-inzichten, gedreven door twee grote gebeurtenissen: de **broncodeleak van Claude Code v2.1.88** (die de interne architectuur blootlegde) en de **1M context window GA-release**. Daarnaast werden nieuwe features zoals **Auto Mode**, **Agent Teams**, **Fast Mode** en **Task Management** breed besproken. De belangrijkste takeaways voor een nieuwe gebruiker: (1) begin met een solide CLAUDE.md en hooks-setup als fundament, (2) benut de 1M context window door /compact op 60% in te zetten, (3) overweeg subagents voor parallelle werkstromen, en (4) implementeer deterministische kwaliteitsgates via hooks in plaats van te vertrouwen op prompt-gebaseerde instructies.

Omdat je systeemontwerp en huidige setup nog niet zijn ingevuld, worden alle inzichten als potentieel nieuw behandeld.

### Hooks

**Voorstel:** Implementeer hooks als deterministische kwaliteitsgates die best-practice-richtlijnen omzetten in afgedwongen regels
**Bron:** Lloyd Pilapil, pixelmojo.io — [Claude Code Hooks Reference: All 12 Events](https://www.pixelmojo.io/blogs/claude-code-hooks-production-quality-ci-cd-patterns)
**Type:** fundamenteel
**Toelichting:** Hooks zijn het krachtigste mechanisme om Claude Code betrouwbaar te maken: ze draaien deterministisch (geen LLM-interpretatie nodig) en ondersteunen nu 4 handler-types (shell, HTTP, prompt, agent). De maart 2026-editie beschrijft 21 lifecycle-events. Dit is de basis voor automatische formatting, linting, testing en notificaties zonder dat je Claude hoeft te vertrouwen op prompt-naleving.

```yaml
# Voorbeeld: auto-format na file writes (in .claude/settings.json)
# hooks:
#   PostToolUse:
#     - matcher: "Write|Edit"
#       command: "npx prettier --write $CLAUDE_FILE_PATH"
#   PostSession:
#     - command: "notify-send 'Claude Code klaar' '$CLAUDE_SUMMARY'"
```

**Voorstel:** Gebruik hooks voor desktop-notificaties wanneer langlopende taken klaar zijn
**Bron:** alexop.dev — [Claude Code Notifications: Get Alerts When Tasks Finish](https://alexop.dev/posts/claude-code-notification-hooks/)
**Type:** klein
**Toelichting:** Vooral nuttig bij achtergrond- of subagent-taken. Voorkomt dat je handmatig moet pollen of een sessie afgelopen is.

## Paradigma-check

### 1. Van prompt engineering naar skill engineering
**Aanname die ter discussie staat:** "Betere prompts = betere output."
**Alternatief:** Encodeer domeinkennis als skills en antipatronen, en gebruik hooks voor deterministische afdwinging. Prompts zijn vluchtig; skills en hooks zijn persistent en betrouwbaar.

### 2. Van single-session naar multi-agent als default
**Aanname die ter discussie staat:** "Eén Claude Code-sessie per taak is voldoende."
**Alternatief:** Met subagents, Agent Teams en task management evolueert Claude Code naar een orchestratieplatform. Parallelle uitvoering met geïsoleerde context is nu het aanbevolen patroon voor alles groter dan een enkele file-edit.
